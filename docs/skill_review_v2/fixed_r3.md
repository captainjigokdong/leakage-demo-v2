# 스킬 검수 fixed_r3

설계서 `fixed_readmission.json`, (가) 조건과 같은 격리 폴더. 에이전트의 마지막 메시지 원문.

---

점검기를 돌린 결과 학습을 막는 문제(차단)는 없었고, 사람이 판단해야 할 경고는 4건 나왔습니다. 설계서를 직접 읽고 데이터와 대조해 문제 1건을 더 찾았습니다. 아직 모델 학습이나 성능 계산은 하지 않았습니다. 보고한 내용은 `findings.json`에 저장했습니다(문제 5건, 가정 4건).

## ① 점검기가 경고한 것

| 대상 | 원리 | 내용 | 수정안 |
|---|---|---|---|
| `split.method` | 가용 시점 (규칙 S.temporal_deploy) | 앞으로 실제 진료에 쓰려는 모델인데, 학습·평가 데이터를 시간 순이 아니라 가족 단위로 무작위로 나눈다. 평가 기간보다 나중의 진료 관행이 학습에 들어간다. | 시간 순 분할로 바꾸고, 가족 단위 묶음은 유지하며, 학습과 평가 사이에 결과 창 길이인 30일 간격을 둔다. |
| `preprocessing.median_impute` / `one_hot` / `standardize` | 적합 범위 (규칙 F.fold_refit) | 하이퍼파라미터 조율은 교차검증으로 하는데, 결측 대치·인코딩·척도화는 학습 데이터 전체에서 한 번만 맞춘다. 그래서 검증 폴드의 정보가 이 단계들에 섞인다. | 세 단계 모두 폴드마다 다시 맞추도록 바꾼다(`fit_scope=train_fold`). |

## ② 추가로 찾은 문제
- **`features.cr_last`**: 설계서 설명에는 "측정법을 함께 넣는다"고 적혀 있지만, 실제 특징 목록에도 전처리에도 측정법 항목이 없습니다. 크레아티닌 측정법은 2155년에 바뀌었고, 예전 방법(jaffe)이 약 0.10 mg/dL 높게 나옵니다. 데이터에는 예전 방법 14,545건, 새 방법 16,661건이 있습니다. 위 수정안대로 시간 순 분할로 바꾸면 학습은 주로 예전 방법, 평가와 실제 사용은 새 방법이 되어 값이 한쪽으로 치우칩니다. 이 값으로 만든 `cr_last_over_hgb`도 같은 영향을 받습니다.
  - **수정안**: 크레아티닌 측정법을 특징으로 추가하거나, 예전 방법의 값을 보정합니다.

①과 ②의 수정을 모두 반영한 설계서를 작업 폴더 밖 임시 폴더에 따로 만들어 점검기를 다시 돌렸고, 차단 0·경고 0이었습니다. 원본 `design.json`은 고치지 않았습니다.

설계서에서 맞는지 따로 확인했고 문제가 없던 부분도 있습니다.
- **추적 불완전 제외 기준(2158-12-01)**: 원외 사망은 최대 180일 늦게 기록되고, 사망 연계 반영일은 2159-07-01입니다. 이 둘로 계산하면 2158-12-03까지 퇴원한 환자는 30일 안 사망이 모두 반영되므로 기준이 맞습니다. 데이터에서도 원외 사망 기록은 가장 늦은 것이 2159-07-01입니다.
- **과거 이력 특징을 등록 번호로 묶은 것**: 이력 특징이 사람 단위가 아니라 등록 번호 단위로 묶여 있습니다. 그래서 등록 번호가 둘인 사람 111명의 이전 입원 일부가 빠집니다. 하지만 등록 번호를 사람 단위로 잇는 작업은 자료 추출 때 한 번에 하므로 예측 시점에는 쓸 수 없습니다. 지금 방식이 맞으니 사람 단위로 고치면 안 됩니다.

## ③ 가정 (참고, 점검기 출력 그대로)
- **분할 키(`split.key`)와 조율 교차검증 키(`model.tuning.cv_key`)**: 가족 정보가 없는 행은 사람 단위로 묶습니다. 기록되지 않은 가족은 학습과 평가에 나뉠 수 있는데, 데이터에서 가족 정보가 없는 비율이 80.4%입니다.
- **에피소드당 고르는 행(`cohort.rows_per_unit`)**: 에피소드의 마지막 입원인지는 퇴원 때 안다고 봅니다.
- **결과 확인 범위(`outcome.ascertainment.scope.sites`)**: A·B 병원 밖의 재입원은 보이지 않습니다. 퇴원 뒤 다른 병원으로 옮긴 환자의 결과율이 29.1%로, 자택 퇴원(14.7%)과 다릅니다.

## 결정 카드 (표본 수와 결과율만)
- 예측 대상 6,706건(환자 4,466명), 결과율 16.7%(1,122건).
- 원내 사망으로 160건, 추적 불완전으로 878건이 제외됐습니다.
- 결과율은 ICU 24.0%, 일반 병동 14.4%, A 병원 16.8%, B 병원 14.9%(228건)입니다.

**결정할 것:** 위 수정안(시간 순 분할, 전처리를 폴드마다 다시 맞추기, 크레아티닌 측정법 추가)을 반영할지 정해 주세요. 규칙상 수정된 설계와 결정 카드를 승인해 확정하기 전에는 성능을 계산하지 않습니다.

점검기가 결과 파일 `checker.json`과 `checker_2.json`을 작업 폴더에 남겼습니다. 두 파일은 같은 원본 설계서를 점검한 결과입니다.
