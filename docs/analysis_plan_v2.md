# 7단계 분석 계획 (v2, 5단계 고정 2026-10-06)

정답표를 열기 전, 실행 결과를 보지 않은 상태에서 고정한다. 여기 적힌 분석은 **미리 정한 분석**이다. 여기 없는 분석을 결과를 본 뒤 더하면 보고서에 **"사후 분석"**으로 표시한다.
근거: `docs/success_criteria_v2.md`(가설·기준), `experiment/scoring_rules.md`(채점), 5단계 사용자 결정(계획 승인 ①~⑩, S1 승인과 조건 1~10). v1 분석 계획(`docs/step7_analysis_plan.md`)은 v1 기록이다.

## 1. 순서

1. 정답표는 암호를 환경 변수로 받아 메모리에서만 복호화한다. 평문은 파일로 쓰지 않는다.
2. 변형 30개의 SHA-256을 정답표·`docs/variants_v2.md`와 대조한다. 어긋나면 멈춘다.
3. 잠긴 채점기(`experiment/grader.py`)로 맹검 채점 → 요약. **채점 결과(grades, summary)를 먼저 커밋한다.**
4. 그다음에야 놓친 사례의 제출을 읽는다. 읽은 뒤에 채점 결과를 바꾸지 않는다. 채점기 버그로 보이는 것은 `docs/known_issues_v2.md`에 적기만 한다.
5. 봉인 기록에서 확인할 것 (정답표를 연 뒤): 수치 차이가 0에 가까운 배치 2개(4b, `docs/stage4b_v2.md`), 서술을 고친 후보 C18·C27·C30 중 뽑힌 것.

## 2. 실행 묶음과 반복

- 실행은 반복 단위로 한다: **1회차 60회**(변형 30 × 조건 2) → **2회차 60회**. 일정은 6단계 `experiment/run.py`가 정한다.
- 2회차를 하지 못하고 1회차만 하면 **60회로 분석**하고 보고서 맨 앞에 그 사실을 밝힌다. 기준과 계산 방법은 같다 (변형 단위 부트스트랩이므로 반복 수와 무관하게 정의된다).
- 분석 묶음: **주 분석**(채택된 실행), **첫 시도 분석**(행마다 첫 시도), **빈칸 = 미탐지 분석**(채택 실행이 없는 행을 `[]` 제출로). 셋 다 같은 지표로 계산하고, 판정은 주 분석으로 한다 (`experiment/analyze.py`).

## 3. 가설 (판정은 주 분석, 따로 판정·따로 보고)

부트스트랩은 **변형 단위 짝지은 복원 추출**(두 조건이 같은 변형을 쓰므로 뽑힌 변형을 두 조건에 같이 씀), 10,000회, 시드 **20261006**, 백분위 2.5%·97.5%.
**변형 안의 배치·반복은 먼저 평균하지 않고 합쳐 센다**: 조건마다 통계량 = 뽑힌 변형들의 Σ분자 / Σ분모. 한 변형 안의 배치·반복은 독립이 아니므로 변형을 묶음 단위로 뽑는다.

| 가설 | 부트스트랩 단위 | 분자 / 분모 (조건마다) | 기준 |
|---|---|---|---|
| **H1a** 탐지율 | 결함 변형 22개 | 탐지된 배치-실행 / 배치-실행 | (가) − (나) 95% CI **하한 > 0** |
| **H1b** 오경보(절대) | (점추정, CI 없음) | (가)의 오경보 총수 / (가)의 깨끗한 변형 제출 수 (8 × 반복 수, 2회면 16) | **≤ 1** |
| **H1c** 오경보(상대) | 깨끗한 변형 8개 | 오경보 총수 / 깨끗한 변형 제출 수 | (가) − (나) 95% CI **상한 < 0** |
| **H2a** 보류 탐지 | 보류 배치가 있는 결함 변형 | 탐지된 보류 배치-실행 / 보류 배치-실행 (공개 배치는 세지 않음) | (가) − (나) 95% CI **하한 > 0** |
| **H2b** 일반화 격차 | 결함 변형 22개 | (가)의 공개 탐지율 − 보류 탐지율 (같은 표본에서 둘 다 계산) | **기준 없음, 기술** (CI 보고, (나)도 함께) |

- 다섯 가지를 하나로 묶지 않는다. 결과 표는 가설마다 한 줄.
- **보조 분석(항목 + 종류)은 판정에 쓰지 않는다.** 같은 계산을 해 나란히 보고하고, 주 분석과 결론이 다르면 조심해서 해석한다.

## 6. 보고서에 미리 적을 한계

- K1·K2·K5 (`docs/known_issues_v2.md`). K1·K5 오경보는 판정에 들어가고 제외값은 참고값이다.
- 보류 사례 정답 칸은 모두 기본값이고, 12개 중 6개는 탐지 칸이 2개 이상(최대 12칸)이다 (K6). 두 조건에 같게 작용한다.
- 정답 칸이 바탕마다 값이 다른 칸인 조합 64 (K6), 서술을 고친 후보 3 (C18·C27·C30).
- **추첨 풀**: 2c 규칙(R1~R3, `docs/injection_log_v2.md`)으로 후보 30개 중 **1개가 추첨에서 제외**되었고(추첨 대상 29), 4b 추첨에서 배치 제외 목록 때문에 4번 넘어갔다 (`docs/stage4b_v2.md`). 보류 12개는 "30개 중 규칙으로 제외되지 않은 후보"에서 뽑은 것이다.
- 정답 칸에 묶음 전체(`cohort`)가 있는 사례(공개 E17·E18, 보류는 정답표를 열어야 앎)는 관대판에서 그 아래 어느 지적이든 탐지가 된다 (엄격판 참고값).
- 보조 분석의 핵심어 사전은 점검기 표현을 더 잘 알아볼 수 있다 ((가)에 유리할 수 있음).
- 데이터 설명서를 두 조건에 모두 준다 (`experiment/scoring_rules.md` 0절). 절대 탐지율은 높아질 수 있으나 두 조건에 같다.
- 6단계 실행 환경의 Python은 lock 파일과 다를 수 있다 (K7).
