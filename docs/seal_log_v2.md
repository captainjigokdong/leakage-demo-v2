# 봉인 기록 (v2 1단계)

v2 새 후보 30개 목록을 `tools/seal.py`로 암호화해 `sealed/candidates.enc`에 봉인했다.
이 문서에는 후보 내용·제목·출처를 적지 않는다. 적는 것은 해시, 개수, 형식, 일치 여부뿐이다.

- 날짜: 2026-10-04
- 암호: 사용자가 새로 정함 (v1 암호 재사용 아님). 영문자·숫자·하이픈, 20자. 사용자가 보관.
- 도구: `tools/seal.py` (PBKDF2-HMAC-SHA256 600,000회 + Fernet, 파일 형식 `LDSEAL1` + salt 16바이트 + 토큰). 도구는 고치지 않았다.
- 평문 위치: 저장소 밖 세션 임시 폴더에만 있었고, 확인이 끝난 뒤 `shred -u`로 지웠다.

## 해시

| 항목 | SHA-256 |
|---|---|
| 평문 목록 (봉인한 바이트 그대로, UTF-8, 줄바꿈 LF, 끝에 줄바꿈 1개) | `f691632cd6f9b9cb2cc8f85ab9f1537e1fab764fe067b854abd7021b85d38def` |
| 정규화 목록 해시 (`tools/draw_holdout.py`의 `catalog_hash`: id 순 정렬 JSON) | `270e9df155b1683a15b0df838cfc247c74c1b9202ce6dea0e616ac2e402bccea` |
| `sealed/candidates.enc` 파일 자체 (8,016바이트) | `642257535d8fde8fe410e0d49715abb74e28fba19cd7db2030f999a9c2ee3447` |

2단계·4단계에서 복호화하면 첫째 해시가 같아야 한다. 정규화 해시는 4단계 추첨 기록과 대조하는 데 쓴다.

## 형식 (구조만)

- CSV (쉼표 구분, 큰따옴표 인용), UTF-8, 줄바꿈 LF
- 머리글 7칸: `id,name,source,question,design_types,how_to_inject,expected_verdict` (v1 `tools/draw_holdout.py`의 `COLUMNS`와 같음)
- 행 30개, 모든 행 7칸, 빈 칸 0개
- `id`: `C01`~`C30`, 30개 모두 다름
- `question`: Q1, Q2, Q3, Q4, Q5, Q7 중 하나
- `design_types`: 고정 / 동적 / 둘다 중 하나 (모두 통과)
- `expected_verdict`: 차단 / 경고 중 하나 (모두 통과)
