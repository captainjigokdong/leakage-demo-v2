# 깨끗한 설계서 검수 readmit_b_r1

설계서 `readmit_b.json`, 스킬 없음, 데이터 설명서 있음. 에이전트의 마지막 메시지 원문.

---

설계서대로 모델링 표를 만들었습니다. 미래 정보가 특징으로 새는 문제는 찾지 못했지만, 고치기를 권하는 설계 문제가 2건 있습니다. 2건 모두 학습을 막을 정도는 아니고, 표는 설계서를 그대로 따랐습니다. 이 2건을 고칠지는 정해 주셔야 합니다. 학습과 성능 계산은 하지 않았고, 설계서와 데이터 파일도 고치지 않았습니다.

**고치기를 권하는 문제**
1. **퇴원약 수(`n_discharge_meds`)**: 입원 두 건으로 나뉜 에피소드에서는 앞 입원의 퇴원약까지 더해집니다. 이런 행 190개의 평균이 인덱스 입원만 세면 1.63인데 합치면 3.05입니다. 5종 이상인 44행은 모두 이 에피소드에서 나옵니다. 그래서 이 특징이 퇴원 때 처방 수보다 "에피소드가 나뉘었는지"를 나타내게 됩니다. 마지막 퇴원의 퇴원약만 세기를 권합니다.
2. **이전 입원 주진단(`prior_dx_group`)**: 같은 병이어도 ICD-9 코드와 ICD-10 코드가 서로 다른 범주가 됩니다(예: 401.9와 I10). 범주 26개 중 절반이 실제 사용 때는 나오지 않는 ICD-9 코드입니다. ICD-10이나 질환군으로 묶기를 권합니다.

**데이터로 확인한 사항 (문제 없음)**
- **추적 불완전 제외 기준일(2158-12-01)**: 원외 사망은 14~179일 뒤에 기록되므로, 이 날짜까지 퇴원한 환자는 30일 안 사망이 모두 반영됩니다.
- **같은 에피소드 안의 이어진 입원**: 모두 에피소드 번호로 묶여 있고, 누락된 이어진 입원은 0건입니다.
- **사망·등록 번호·가족 연결**: 서로 어긋나는 곳이 없습니다.
- **퇴원 뒤에 보고된 기록**: 검사 4.5%와 활력징후 0.75%는 퇴원 뒤에 보고·입력됩니다. 보고·입력 시각 기준 창으로 모두 걸렀습니다.

**준비된 데이터**
- 대상은 6,514건(4,373명)입니다. 학습 4,564건, 평가 1,950건으로 나누었고, 두 부분에 같은 사람은 없습니다.
- 결과율은 전체 0.145(재입원 0.139, 사망 0.009)입니다.
- 결측은 최저 혈색소 5.7%와 이전 입원 주진단 70.3%(이전 입원이 없는 경우)이고, 나머지 특징은 결측이 없습니다.
- 대치·원핫·표준화는 설계대로 학습 폴드에서만 맞추도록 아직 적용하지 않았습니다.

**제가 정해 둔 가정과 확인할 수 없는 부분** (상세는 보고서)
- 교차검증 폴드 수가 설계에 없어 학습 전에 정해야 합니다. 5개를 제안합니다.
- 과거력 특징은 설계대로 환자 등록 번호로 모았습니다. 사람 단위 연결은 자료 추출 때 만들어진 것이라 예측 시점에는 쓸 수 없기 때문입니다.
- 기록되지 않은 가족은 학습과 평가에 나뉘어 들어갈 수 있는데, 데이터로는 찾아낼 수 없습니다.
- 다른 병원 재입원을 얼마나 놓쳤는지도 알 수 없습니다. 전원 퇴원의 결과율(0.125)이 자택 퇴원(0.147)보다 낮은 것이 실제 차이인지 덜 찾아낸 것인지 가릴 수 없습니다.
