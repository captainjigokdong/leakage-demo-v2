# 깨끗한 설계서 검수 readmit_a_r2

설계서 `readmit_a.json`, 스킬 없음, 데이터 설명서 없음. 에이전트의 마지막 메시지 원문.

---

데이터를 점검해 보니 설계에 정보 누출이나 결과 정의 오류처럼 진행을 막을 문제는 없었습니다. 설계대로 모델링용 표를 만들었고, 고쳐야 할 문제 1건과 가정·점검 불가 6건을 `findings.json`에 저장했습니다. 모델 학습, 성능 계산, 학습 부분에 맞추는 전처리(대치·원핫·표준화)는 하지 않았습니다. 설계서와 데이터 파일도 고치지 않았습니다.

## 데이터와 맞는다고 확인한 것
- **시점 누출:** tp(퇴원 시각) 뒤에 생기는 값을 쓰는 특징은 없습니다.
  - 진단은 퇴원 뒤 최소 24시간이 지나야 코딩되므로, 인덱스 입원 진단은 설계의 시간 창에서 자연히 빠집니다.
  - 퇴원약은 퇴원 1~6시간 전에, 투석 오더는 퇴원 28시간 이상 전에 나옵니다.
  - 결과의 대리 지표(입원 예약, 추적 외래)는 특징에 쓰이지 않습니다.
- **사망 추적:** 원외 사망은 사망 뒤 14~179일 사이에 기록됩니다. 따라서 2158-12-01까지 퇴원한 환자는 30일 안 사망이 사망 연계 반영일(2159-07-01) 전에 모두 잡힙니다.
- **크레아티닌 보정:** 두 병원 모두 2155-01-01을 경계로 측정법이 jaffe에서 enzymatic으로 바뀌었습니다. 같은 환자 안에서 두 측정법의 차이(중앙값)는 0.10 mg/dL로, 설계의 보정값과 같습니다.
- **분할:** 학습과 평가에 함께 들어간 가족·사람은 0입니다. 한 사람의 등록 번호들은 family_id가 서로 다르지 않습니다. 중복 입원 기록은 없습니다.
- **에피소드:** 두 기록으로 된 에피소드는 220개로, 모두 앞 기록이 전원(transfer)으로 끝나고 1시간 안에 다음 입원이 이어집니다.
- **예정 입원:** elective 입원 590건 중 572건에 예약 기록이 있습니다.

## 보고한 문제 (`findings.json`)
| 항목 | 종류 | 요지 |
|---|---|---|
| `cr_last.assessment.method` | 문제 | 문장이 "측정법 자체는 특징으로 "에서 끊겼습니다. 특징 목록에 측정법이 없어 "넣지 않는다"로 보고 진행했고, 설계서 문구를 고쳐야 합니다 |
| `outcome.censoring.lost_to_followup` | 가정 | 다른 병원으로 전원된 퇴원 751건은 그 병원 재입원이 보이지 않아 음성으로 셉니다. 결과율은 transfer 12.5%, home 14.7%입니다. 퇴원처(discharge_status)가 예측 변수이기도 해서 모델이 이 차이를 위험 차이로 배울 수 있습니다 |
| 과거 이력 특징 4개 | 가정 | 자료가 2150년에 시작해서 학습 초기 입원은 과거 이력이 잘려 있습니다. 시작 시점 제한이 없는 진단·문제 목록 특징은 학습과 평가에서 볼 수 있는 이력 길이가 달라집니다 |
| `age` | 점검 불가 | 작업 폴더에 데이터 설명서가 없고 생년월일도 없어 나이 정의를 확인할 수 없습니다. 95세로 잘린 환자(입원 176건)의 나이는 하한값입니다 |
| 이력 특징의 `history_key` | 점검 불가 | "person_id는 퇴원 시점에 알 수 없다"는 전제를 데이터로 확인할 수 없습니다 (연결 시각 열이 없음) |
| `sbp_last` 정렬 기준 | 가정 | 입력 시각 기준이라 7,724건 중 44건에서 가장 늦게 잰 값이 아닌 값이 선택됩니다 |
| B 병원 하위 집단 | 가정 | 평가 47건(사건 7), 학습 156건(사건 20)으로 표본이 매우 작아 신뢰구간이 필수입니다 |

## 준비한 표
- **코호트:** 에피소드 7,504 → 성인 7,504 → 생존 퇴원 7,344 → 추적 완료 6,514
- **분할:** 학습 4,533건(사건 661), 평가 4,533 대신 1,438건(사건 213)입니다. 경계 시각 뒤에 행이 있는 묶음의 경계 이전 행과 간격 안 행 543건은 쓰지 않습니다.
- **결과율:** 전체 14.5%입니다 (재입원 13.9%, 사망 0.9%).
- **결측:** hgb_min과 cr_last_over_hgb만 5.5% 비어 있습니다. 대치는 학습 부분에서 맞춰야 하므로 하지 않았습니다.
