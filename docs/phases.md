# 단계별 계획 (v2)

전체 계획은 `docs/v2_plan.md`. 이 문서는 단계마다 할 일과 완료 기준만 적는다. 표의 "시행착오 #"은 `v2_plan.md` 2절 표의 번호다.

각 단계는 **새 세션**에서 "docs/phases.md의 N단계를 진행해"로 시작한다.

**단계 시작 체크리스트** (모든 단계 공통, 시행착오 13)
- [ ] 앞 단계 PR이 main에 병합됐는지 확인. 안 됐으면 멈추고 사용자에게 알린다. (1단계만: main에 0단계 커밋이 있는지로 확인)
- [ ] 이번 단계가 봉인 파일을 열어도 되는 단계인지 아래 표로 확인.
- [ ] 계획을 사용자에게 먼저 보여 주고 확인받는다.

**봉인 파일을 볼 수 있는 단계** (사용자가 암호를 직접 줄 때만)

| 단계 | 봉인 파일 |
|---|---|
| 0, 3, 5, 6, 8 | **열지 않음** (3단계 스킬 세션은 어떤 경우에도 보지 않는다) |
| 1 | 후보 목록을 암호화만 한다 (사용자가 붙여 넣은 평문 → 바로 `*.enc`) |
| 2 | 2a·2c만: 후보 30개를 열어 형식 확정(2a)·주입 코드 작성(2c). 새 후보분 기록·주입 코드는 봉인. **2b는 열지 않음** |
| 4 | 보류 추첨, 변형 생성, 정답표 봉인 |
| 7 | 정답표를 열어 채점 |

**봉인 파일 목록** (모두 v2 봉인 암호. 사용자가 암호를 직접 줄 때만 연다)

| 파일 | 만든 단계 | 내용 (종류만) | 해시 기록 | 열 수 있는 단계 |
|---|---|---|---|---|
| `sealed/candidates.enc` | 1 | 새 후보 30개 목록 | `docs/seal_log_v2.md` | 2a, 2c, 4, 7 |
| `sealed/stage2a_record.enc` | 2a | 2a 작업 기록 (새 후보 대조표, 형식 확정 과정) | `docs/injection_log_v2.md` | 2c, 4, 7 |

- **3단계는 어느 봉인 파일도 열지 않는다.** 2b, 5, 6, 8단계도 열지 않는다.
- 2c·4단계에서 새로 만드는 봉인 파일은 만들 때 이 표에 더한다.
